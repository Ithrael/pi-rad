pi-red

God mode for pi.

A pi package that adds the power-user features pi leaves out — isolated subagents, read-only plan mode, lean tool sets, and security-research framing — without forking pi. Install once; it survives pi update.

git clone https://github.com/ithrael/pi-red && cd pi-red && bash install.sh

Feature unlocks

Subagents

Delegate to isolated pi processes in single, parallel, or chained mode. Their own context window, tools, and model.

Plan mode

A read-only planning posture with edit/write hard-blocked. Toggle with /plan or ctrl+alt+p.

Lean tools

Trim redundant exploration tools, or go minimal with read/bash/edit/write only.

Security research framing

Recognizes CTF, vuln research, and authorized pentest work and frames it correctly so the model does the work.

Auto trust

Skip the project trust prompt and remember the decision.

Attribution off

Strip provider attribution and tracking headers from outgoing requests.

Try it

# install, then launch with pi-red enabled
pi-red

/red
